# Перенос мультяшного стиля в «Наш дом» — план

> Выбор Вани 07.10: мультяшный вариант из `lab/cartoon.js`. Эталон картинки — `lab/?v=cartoon` (лаборатория остаётся как образец, не трогаем).

**Цель:** главная сцена (`room.js`) выглядит как `lab/?v=cartoon` и остаётся быстрой на Radeon 760M (≤ 10 мс при Full HD pr 1), при этом всё живое работает: коты, записки, расстановка, своя комната, время суток, погода, подарки.

**Архитектура:** общий набор стиля — новый модуль `toon.js` (палитра, тун-материал с тёплыми тенями и ободком, обводка-оболочка, сборщик статики в один меш, ореолы, пятна-тени, пост-проход). Неподвижную обстановку `room.js` строит заново из набора (как в лаборатории). Всё подвижное и сменное (столы и вещи `furniture.js`, подарки `decor.js`, коты, записки, книги, полароиды) переводится одной функцией `toonify(root)`: стандартные материалы → тун, плюс обводка той же геометрии (работает и для SkinnedMesh котов).

**Стек:** three.js 0.170 (importmap), без сборки; проверка — снимки через `scratchpad/recv.mjs` (:8199) и замер `readPixels`.

## Файлы
- Создать `toon.js` — набор стиля (вынут из `lab/cartoon.js`): `P`, `createToon(THREE, renderer)` → `{ toon(opts), outlineOf(mesh, w, color), toonify(root, opts), Batch, canvasTex, halos(list), blobs(list), post }`.
- Изменить `room.js`: рендер (вместо EffectComposer/GTAO/объёма/bloom/SMAA — MSAA-цель 8 бит sRGB + один проход виньетки), ступени качества (MSAA 4/2/0, тень 2048/2048/1024), свет и `applyTime` под тун, неподвижная обстановка из `Batch`, небо в окне — мультяшные облака, toonify для динамики.
- Удалить `volumetric.js` (больше не нужен; плоские лучи из окна остаются).
- `roomstyle.js` — краски/обои/полы перерисовать «от руки» (агент).
- `furniture.js`, `decor.js`, `cats.js`, `catmesh.js` — без переписывания: их вещи проходят через `toonify`; доводка пропорций — отдельной задачей после.

## Задачи
1. **toon.js.** Вынести из `lab/cartoon.js` градиент 3 полосы + patch (uTint/uRim), фабрику `toon`, `Batch` (add/addMesh/group/finish → solid + hull), ореолы, пятна-тени, пост. Новое: `outlineOf(mesh)` — дочерний меш с той же геометрией, `MeshBasicMaterial` BackSide + сдвиг вершины по нормали в clip-space (onBeforeCompile; для skinning — `transformedNormal`); для геометрии с разрезанными нормалями — копия с `mergeVertices` по позиции. `toonify(root)` — обходит меши: Standard/Physical → `toon({color, map, emissive, emissiveMap, transparent, opacity, side, alphaTest})` (кэш по исходному материалу), Basic/Shader/Points/Sprite не трогает, обводка — если меш непрозрачный и `!userData.noOutline`.
   Проверка: в `lab/` временно `?v=cartoon` не трогаем; `node --check`-эквивалент `npx acorn`; дальше проверяется в задаче 2.
2. **Рендер в room.js.** Убрать composer-цепочку, `RoomEnvironment`, `VolumetricPass`; MSAA-цель + пост из toon.js; `TIERS = [{msaa:4, shadow:2048}, {msaa:2, shadow:2048}, {msaa:0, shadow:1024}]`, тень лампы выключена всегда (точечная тень = 6 проходов). `gfx.js` и его тест не меняются. Проверка: страница без ошибок, `__room` жив, снимок.
3. **Свет и время суток.** Полусфера ~1.75 днём (тун без окружения темнеет), заполняющий направленный, солнце — сила по `tp.power` в новой шкале; ночь — сиреневый тинт, лампа = точечный без тени + ореол. Небо `drawSky`: облака — пухлые кляксы с подложкой (как в лаборатории), дома и огни города оставить. Проверка: снимки `?hour=13`, `?hour=19`, `?hour=23`, `?weather=rain`.
4. **Обстановка.** Через `Batch`: стены/пол — отдельные меши с холстами `roomstyle` (тун), панель и молдинги, окно (откосы, рама, подоконник, блики, кактус), карниз и шторы с подхватами, гирлянда (провисы, лампочки, ореолы), коврик, кресло-мешок с сердцем, большое растение, корзинка, лампа, растение на столе, кружка с паром, лоток, ноутбук (группа `laptop` и `lid` сохраняются — на них завязаны `goScreen` и клики; экран — холст 2048 в стиле лаборатории), полка с альбомами (книги динамические → toonify). Координаты — из `room.js` (TRAY, LAPTOP, MUG, полки), не из `lab/layout.js`. Пятна-тени под предметами. Проверка: снимок общего плана рядом с `lab` — тот же уровень.
5. **Динамика.** `toonify` для: стол `buildDesk` (в `applyRoom`), вещи `placer` (при `sync`), подарки `decor`, коты (`createCats` → корень), записки (бумага с текстом — без затемнения текста: tint только на тени), полароиды, книги. Проверка: клик по ноутбуку, бросок записки, «расставить», кот ходит — снимки + консоль без ошибок.
6. **roomstyle.js (агент).** 12 стен и 6 полов «от руки»: плоские цвета, рисованные полосы/цветочки/доски как в `lab/cartoon.js`; API `paintWall/paintFloor/WALLS/FLOORS` не меняется. Проверка: снимки трёх разных стен и полов.
7. **Финал.** `node tests/*.mjs`, замер `bench` в Full HD pr 1 и 1.5 (≤ 10 / ≤ 14 мс), снимки день/вечер/ночь/дождь, выкат `vercel deploy --prod --yes`, HANDOFF/память.
