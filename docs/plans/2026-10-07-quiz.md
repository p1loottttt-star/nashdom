# Тесты для пар — план

> Исполнение inline в этой сессии. Спека: `docs/specs/2026-10-07-quiz-design.md`.

1. **quizlogic.js + tests/quiz.test.mjs (TDD).** Сначала тест: `whoRows` (перевод «я/ты/оба» в абсолютных людей, согласие, процент), `typeResult` (частый ключ, ничья по порядку), `knowScore` (угадано каждым), `validate(quiz)` (целостность записи базы). Запуск `node tests/quiz.test.mjs` → падает; потом код → проходит.
2. **quizdb.js.** 15 тестов (по 5 форматов who/type/know), `TOPICS`. Тест прогоняет `validate` по всей базе.
3. **Баллы.** `catalog.js` EARN `quiz: [10, 3, 'тест вдвоём']`, `schema.sql` award `('quiz', 10, 3)`, `tests/catalog.test.mjs` сверяет все EARN с SQL.
4. **quiz.js.** `renderQuiz(el)`: каталог (темы, поиск, «тебя ждут»), «пройденные», прохождение по одному вопросу, итоги трёх форматов, «позвать», запись ответов, начисление, снятие приглашения. `initQuizBadge()` — счётчик на иконках и тост о приглашении.
5. **desktop.js / index.html.** Приложение `quiz` в APPS, иконка и кнопка дока «🧩 Тесты», стили `qz-`.
6. **Проверка.** Локальный режим, две вкладки (`/` и `/?as=b`): пройти каждый формат за обоих, позвать, счётчик, итоги, баллы; снимки окна; тесты; выкат.
