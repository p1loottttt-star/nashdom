# Тесты для пар — дизайн

07.10.2026, согласовано с Ваней. Приложение «Тесты» в ноутбуке.

## Форматы (по 5 тестов, тексты свои)
- **who — «Кто из нас…»**: 12 утверждений, ответ «я / {партнёр} / оба». Итог: где сошлись (с именем), где «спорно», процент согласия.
- **type — «Какой ты…»**: 7 вопросов, у ответа — ключ результата; итог = самый частый ключ (ничья — по порядку результатов). Свой результат виден сразу, пара — две карточки и строка «вместе вы — X и Y».
- **know — «Знаешь…»**: 8 вопросов, на каждый два ответа: «про себя» и «что выберет {партнёр}». Итог: сколько угадал каждый, разбор вопросов.

## Приложение
- Каталог: фишки тем, поиск по названию/теме, блок «тебя ждут» сверху; вкладка «пройденные».
- Карточка: эмодзи, название, тема, число вопросов, «ты ✓ / {имя} ⏳». Кнопки «пройти» и «позвать {имя}».
- Позвать: запись `quizask` → у партнёра тост и счётчик на иконке «Тесты» (рабочий стол и док). Пройдя тест, приглашение снимается.
- Ответы партнёра скрыты, пока не прошёл сам; итог пары — когда прошли оба. Пройти заново можно (ответы перезаписываются).
- Баллы: `award('quiz', id теста)` тому, кто закончил вторым: +10, до 3 в день (catalog.js EARN + schema.sql award).
- Стиль: бумага, чернила, Caveat, неровные края; классы с префиксом `qz-`.

## Данные
- `quiz` / `<тест>:<человек>` = `{ test, user, answers, at }`; `quizask` / `<тест>:<кому>` = `{ test, from, to, at }`. Общее хранилище дома, новых таблиц нет.
- who: `answers[i]` ∈ `me | you | both` (относительно отвечающего); type: индекс варианта; know: `{ self, guess }`.
