# «Тесты»: каталог по образцу pikuco.ru (11.10.2026)

Согласовано с Ваней 11.10. Права на картинки — память `feedback-quiz-real-images`.

## Что берём у образца
pikuco.ru/tests: рубрики, сортировка, фильтр по формату и длине, поиск, «случайный тест»; карточка с обложкой и числом вопросов; экран старта («Поехали!»); вопрос с фото слева и вариантами справа, «вопрос 7/15», «шаг назад», «сброс»; итог «кто ты из» — герой с описанием, у каждого героя процент. Глобальной статистики «сколько людей получили» у нас нет (данные пары закрыты) — вместо неё твоя похожесть на каждого героя.

Не берём: древо (текстовый квест), челлендж, диаграмму, рейтинги и комментарии, 18+.

## Каталог
- Рубрики (`RUBRICS`): кино и сериалы, анимация и аниме, игры, животные и природа, еда, путешествия, характер, для пар. Старые 20 тестов переезжают в них (кто из нас / знаешь / это или то / чек-лист / вечер → «для пар»).
- Формат: кто ты из (`type`), турнир (`cup`), тирлист (`tier`), викторина (`trivia`), парные (`who|know|pick|list|evening`).
- Длина: до 10 / 10–20 / больше 20 (по `length(q)`).
- Сортировка: популярные (`pop` — вес по топу pikuco), новые (`added`), ещё не пройденные.
- Поиск по названию, рубрике, формату, франшизе.
- «Случайный тест» — среди непройденных (если пройдено всё — среди всех).
- Вопрос дня, «тебя ждут» — наверху, как сейчас.
- Карточка: фото-обложка на ленте (или старая наклейка у старых тестов), формат · рубрика · число вопросов, «ты ✓ / партнёр …», «пройти / итоги / позвать», у фан-тестов строка «фан-тест».

## Форматы
**type — кто ты из / какой ты** (расширение существующего). Результаты `{ title, text, img }`; вопросы `{ q, img?, a: [[текст, ключ]] }`, 4–8 вариантов. Экран старта: обложка, описание, «N вопросов», «Поехали!». В прохождении «шаг назад» и «сброс». Итог: герой (имя, характер, фото его мира) + проценты по всем героям (доля ответов с этим ключом). С партнёром: две карточки, «вместе вы — X и Y», «ответили одинаково N из M».

**cup — турнир 16→1.** `items: [{ t, img }]` ×16. Сетка перемешана одинаково для обоих (зерно — id теста). Ответ — номера победителей 15 матчей по порядку. Итог: победитель, финал, у каждого — сколько матчей выиграл. С партнёром: оба победителя, «общий топ-3» по сумме побед, «в первом круге сошлись N из 8».

**tier — тирлист.** `items` ×20–24, полки `топ / норм / так себе / мимо`. Раскладка: перетаскивание на полку или нажатие на фото → выбор полки. Ответ — номер полки на каждый пункт. С партнёром: две доски рядом, «на одной полке N из M», «горячие споры» — разница в 2+ полки.

**trivia — викторина.** `questions: [{ q, img?, a: [варианты], ok }]`. После ответа сразу верно/неверно и правильный вариант. Итог: счёт и звание (`knowTitle`). С партнёром: кто знает лучше, по вопросам — оба ответа.

## Герои и картинки
- Герои франшиз — только в тексте; у теста поле `fan: 'Гарри Поттер'` → «фан-тест по вселенной «Гарри Поттер», не связан с правообладателем» на карточке, старте и итоге.
- Без логотипов, кадров, артов, фан-арта, генераций, своих рисунков героев. Новых наклеек для тестов не рисуем.
- Фото — только свободные: Openverse (CC0, PDM, CC BY, CC BY-SA; без NC/ND, без mature). Вопрос — фото по смыслу; результат-герой — его мир (предметы, место, атмосфера).
- В пакете теста `imgs: { ключ: 'англ. запрос' }`, в данных — ключи. Файлы `public/quiz/<ключ>.webp` (640 px по ширине, ~35 КБ), сведения `public/quiz/credits.json`: `{ ключ: { by, src, lic, lic_url, title } }`.
- Подпись под фото: «фото: автор · лицензия» ссылкой на источник. В «Тестах» — страничка «авторы фото».
- `scripts/quizimg.mjs`: `search` — кандидаты из Openverse для ключей без файла → контактный лист в `shots/qimg/` (выбираю глазами) → `picks.json`; `fetch` — скачать выбранное, ужать в WebP через Chrome (playwright-core), дописать `credits.json`.

## Код
- `quizdb.js` — лёгкий каталог: старые тесты целиком + записи новых `{ id, kind, rubric, title, desc, n, pop, added, cover, fan? }`.
- `quizpacks/<id>.js` — полный тест, грузится `import()` при старте/итогах (Vite режет на куски).
- `quizlogic.js` — `typePercents`, `typeSame`, `cupBracket`, `cupScore`, `tierScore`, `triviaScore`, `validate` для новых форматов; тесты в `tests/quiz.test.mjs`, плюс проверка: каждый пакет проходит `validate`, у каждого ключа фото есть файл и строка в `credits.json`.
- Хранилище прежнее: `quiz/<тест>:<человек> = { test, user, answers, at }`, `quizask`, `award('quiz', id)`.
- Плавность: фото `loading=lazy`, `decoding=async`, с размерами; в комнате ничего не грузится, пока не открыты «Тесты». Стенд `tests/perf/bench.mjs --no-profile` до и после.
