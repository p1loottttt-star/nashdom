# Альбомы как редакторы фотокниг (11.10.2026)

Ваня (09.10): альбомы — «как настоящие редакторы фотокниг: шрифты, свободная раскладка, шаблоны стилей». Разбор: `docs/specs/2026-10-10-mechanics-research.md` §2 + Mixbook (вкладки фото/раскладки/фоны/наклейки, 700+ раскладок по числу фото, тема книги, автозаполнение, фото двигается и масштабируется внутри рамки, замена местами, на весь разворот), Saal Digital/Lightroom Blurb (автораскладка по ориентации и дате), Project Life/LiveStamp/Tomobook (скрапбук: washi, штампы дат, карточки, наборы оформления), Shuffles (свободные слои).

## Решения Вани
- **Гибрид:** разворот начинается с раскладки темы (слоты под фото, подпись, лента), любую вещь можно вытащить и положить свободно.
- **Правка по очереди без потерь:** каждая страница — отдельная запись; правки на разных страницах не затирают друг друга; на одной странице — плашка «<имя> сейчас на этой странице».
- **4 темы в первом выпуске:** крафт и скотч, путешествие, плёнка и кино, нежная акварель.

## Устройство
- HTML/CSS-редактор (развитие `albums.js`), все координаты в % страницы. Не холст-библиотека и не 3D.
- **Данные.** `albums/<id>`: `{ title, theme, cover, order, pageIds }`. `albumpage/<pageId>`: `{ album, layout, slots: { <slotId>: { photo, cx, cy, zoom } }, items: [{ id, type: photo|text|tape|sticker, x, y, w, rot, z, … }], by, at }`. Старые `album.pages` переносятся при первом открытии (`migrate()`), старые поля альбома не удаляются до переноса.
- **Тема** (`albumthemes.js`): бумага/фон (CSS, процедурные текстуры), обложка, 2 рукописных шрифта с кириллицей, 5 чернил, рамка фото (полароид / белый край / кадр плёнки / рваный край), ленты, наклейки и штампы (рисованные, в стиле `doodles.js`), 8–10 раскладок. Смена темы перекрашивает альбом, фото остаются.
- **Раскладки** — данные: слоты `{ id, x, y, w, h, rot }` (ориентация из w/h), подпись `{ x, y, w }`, ленты `{ x, y, rot }`. На 1–5 фото + «на весь разворот». «Перемешать» — другая раскладка с тем же числом слотов, фото сохраняются по порядку.
- **Правка.** Вкладки Фото / Раскладки / Украшения / Текст (телефон — нижний лист, одна страница). Фото в слот перетаскиванием (занят — меняются местами); двойной клик/тап — кадрирование внутри рамки (сдвиг, колесо/щипок); вытащить из слота — свободная вещь. Свободные вещи: ручки размер/поворот, слои, дубль, удалить, магниты к центру и краям, Ctrl+Z/Y, Delete, стрелки. Миниатюры разворотов внизу, перестановка перетаскиванием.
- **Чтение.** Картонная обложка темы, листание загибом (CSS 3D), стрелки/свайп.

## Этапы (каждый выкатывается)
1. Данные + перенос, 4 темы (бумага, шрифты, рамки, раскладки), фото в слотах, кадрирование, смена темы, «перемешать», чтение с листанием.
2. Украшения (ленты, наклейки, штампы), шрифты и чернила подписей, направляющие, отмена/повтор.
3. Автозаполнение по дате и ориентации (EXIF), фото из галереи, перестановка разворотов, плашка присутствия.

## Проверка
`tests/albums.test.mjs`: каждая раскладка внутри страницы, у каждой темы есть раскладки на 1–5 фото, перенос старого альбома без потерь, «перемешать» сохраняет фото, автозаполнение. Стенд двумя вкладками (`?local` и `?local&as=b`): правки на разных страницах не теряются. Стенд плавности на открытии и листании.
