# Стекло в комнате (Э1) — спека

12.10.2026. Ваня выбрал концепцию «Стекло» из `lab/ui3/glass.html`, **без вкладки «Вместе»**: игры и тесты остаются в ноутбуке. Этапы: **Э1 — комната** (эта спека) → Э2 — редактор альбома (`glass.html#album`) → Э3 — окна ноутбука (перед Э3 решить: скрапбук внутри окон остаётся или окна тоже в стекле).

## 1. Экран комнаты

| Место | Что | Откуда данные | Нажатие |
|---|---|---|---|
| слева сверху | **«мы»**: два аватара, зелёная точка у партнёра в сети; «Ваня и Соня · 744 дня» / «Соня дома · у неё 22:43, +9°, дождь» | `store.me/partner`, `since()`, `live.presence()`, погода — `fetchWeather(partner.city)` + `cityHour` (как в profile.js) | профиль в ноутбуке |
| по центру сверху | **вопрос дня**: огонёк + «Вопрос дня · серия 12 — Соня уже ответила» | `qday` (quizlogic: `qdayStreak`, `dayStr`) | ноутбук → «Тесты» на вопросе дня |
| справа сверху | **♥ баланс** и **колокольчик** со счётчиком | `store.balance()`, список дел (§3) | история начислений (магазин, вкладка «как заработать») / список дел |
| справа под ними | **карточка** нового (§3) | | переход к делу |
| снизу | **полоса**: Память · [＋ Записка] · Дом · Ноутбук | | лист «Память» / окно записки / лист «Дом» / ноутбук |

- Партнёр не в сети — «Соня не в сети»; у партнёра нет города — без погоды и времени; партнёра нет — «мы» показывает только меня и «позови вторую половинку» (ведёт в профиль, где ссылка-приглашение).
- Оба ответили на вопрос дня — чип сжимается до огонька с числом серии.
- Уходят: `.hud` (погода, «написать», «расставить», звук) и `#tip`. Свой город — в профиле (уже есть). Звук и «расставить» — в листе «Дом».
- Стекло прячется в тех же состояниях, что `.hud` сейчас: `body.zoomed / busy / editing / aim`, плюс открытый ноутбук и альбом.
- Телефон (≤ 760 px): у «мы» только аватары, у вопроса дня — «Вопрос дня» с огоньком, у записки — только значок; полоса во всю ширину.

## 2. Листы «Память» и «Дом»

Стеклянный лист поднимается снизу над полосой (как `.sheet` в прототипе), комната видна сверху. Закрывается ×, Esc, нажатием мимо, повторным нажатием на вкладку. Открытый лист подсвечивает свою вкладку.

- **Память**: обложки альбомов (цвет + фото обложки, название, число страниц) и «＋ альбом» → `openAlbum` (как с полки, через `openShelfAlbum`); ниже две строки-ссылки: «Галерея» и «Мысли» → ноутбук на этом приложении.
- **Дом**: «Расставить» (со счётчиком коробок `placer.boxCount()`) → режим расстановки; «Магазин» → ноутбук «Магазин»; «Звук» — переключатель (`sfx.toggleMute`).

## 3. Уведомления: карточка + колокольчик

**Список дел вычисляется из store**, ничего нового не хранится. Чистая функция `pending(snap)` в `notifylogic.js` получает снимок и возвращает дела по порядку важности:

| Дело | Условие | Переход |
|---|---|---|
| записка | записка партнёра, не прочитана, не в мусорке | камера к столу (обычное чтение записок) |
| подарок | `ledger`: `reason=gift`, `to_user=я`, `!opened` | камера к столу (коробка на столе) |
| ход | партия, где `isMine` | ноутбук → «Игры», эта партия |
| зовёт в тест | `quizask` мне | ноутбук → «Тесты» |
| вопрос дня | партнёр ответил сегодня, я нет | ноутбук → «Тесты», вопрос дня |

- Счётчик колокольчика = длина списка. Колокольчик открывает стеклянный список (под ним, справа), строки — те же дела.
- **Карточка**: когда после загрузки в списке появляется новое дело (ключ дела не встречался в этой вкладке), сверху справа всплывает стеклянная карточка с аватаром партнёра, заголовком («Соня написала записку») и строкой-подробностью, ~6 с, потом уходит. Несколько подряд — показывается последняя, остальные уже в списке.
- «Соня пришла домой» (переход presence: не в сети → в сети) — только карточка, в список не идёт.
- Тосты-приглашения в `quiz.js` (`badge`, `store.on('quizask'|'qday')`) и `games.js` (`badge`, `store.on('game')`) убираются — их заменяет карточка. Счётчики на значках ноутбука остаются. Тосты «+5 ♥», «не сохранилось», радио — остаются, но в стекле.

## 4. Как устроено

- `glass.js` (корень, из `lab/ui3/glass.js`): `glass(el)` строит карту линзы и `backdrop-filter: url(#…)` по размеру элемента; пересчёт при изменении размера (ResizeObserver, карта кэшируется по w×h×r). Блик кромки и тень — CSS-классом `.lg` (как в прототипе).
- **Плавность** (Radeon 760M): преломление над живым WebGL-кадром стоит GPU каждый кадр. Замер стендом `tests/perf/glass.mjs`: время кадра комнаты со стеклом и с `body.flatglass` (стекло без `url()`, только размытие), от сети. Запасной путь: когда автоподстройка gfx.js упирается в верхнюю ступень (`tier === TOP_TIER`), включается `flatglass`. Графику комнаты ради стекла не понижаем.
- `hud.js` (новый) — разметка и поведение верхних капсул, полосы, листов и карточек; `notifylogic.js` — `pending()` (чисто, тест `tests/notify.test.mjs`); room.js отдаёт hud'у действия (`write`, `arrange`, `goScreen(app)`, `openShelfAlbum`, `toDesk`, `isIdle`).
- Ноутбук открывается сразу на нужном месте: `goScreen(app, opts)` → `openDesktop(app, done, opts)` → `renderQuiz/renderGames` принимают `opts` (`{ day: true }`, `{ match: id }`).
- Шрифт интерфейса — Onest (`@fontsource/onest`, кириллица); Caveat — только для написанного людьми. Значки — ~12 штук Phosphor (MIT) вписаны SVG-путями в `icons.js`, без шрифта-иконок.
- Имена классов — с префиксом `lg-` (`.tray/.slot/.cap/.tnote/.lay/.pcard/.shead/.stage` уже заняты).
