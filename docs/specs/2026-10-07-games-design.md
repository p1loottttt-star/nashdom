# Мини-игры для пары — дизайн

07.10.2026, согласовано с Ваней. Приложение «Игры» (🎲) в ноутбуке. Все игры — **по ходам**: каждый ходит, когда заходит; если оба онлайн, ходы видны сразу (хранилище синхронизируется вживую).

## Оболочка
- Список: «новая игра» (4 карточки) → партия с партнёром, создатель ходит первым; «твой ход», «ждём {имя}», последние законченные со счётом.
- Партия = `game/<id>` = `{ kind, players: [создатель, партнёр], turn, state, score, done, at }`. Модуль игры рисует партию и сохраняет ход через общий `save(patch)`.
- Счётчик «твой ход» на иконке и подсказка при входе — как у «Тестов».
- Баллы: `award('game', id партии)` при завершении: +5, до 5 в день (EARN + schema.sql).

## Игры
- **«Одна волна» (wave)** — кооператив, 5 раундов. Ведущий выбирает одну из двух шкал («скучно ↔ романтично»…; ~40 шкал), видит скрытую цель 0–100 и пишет подсказку. Второй ставит стрелку. Очки команды: ≤4 → 4, ≤11 → 3, ≤18 → 2, иначе 0. Угадавший сразу становится ведущим следующего раунда (ход остаётся у него). Итог — из 20, с оценкой.
- **«Рисуй — угадывай» (draw)** — кооператив, 6 раундов. Рисующий выбирает одно из трёх слов (~150 слов) и рисует; штрихи хранятся с временем, угадывающий смотрит повтор и вводит ответ (регистр, «ё», пробелы не важны). Подсказка открывает букву (−1 очко), «сдаюсь» — 0. Очки: 3 − подсказки. Угадавший рисует следующим.
- **Крестики-нолики сердечками (ttt)** — поле 3×3, ❤️ у создателя, 🐾 у партнёра, ничья возможна; «ещё партию» — новая партия, первым ходит другой.
- **Морской бой (battle)** — поле 8×8, флот 4+3+3+2+2+1+1 (без касаний), «расставить случайно»; оба расставляют, потом стрельба; попал — стреляешь ещё; побеждает потопивший весь флот.
